# Shopify draft theme files (Lumin, theme ID 198428983680)

Source of truth for the custom sections and JSON templates pushed to the
draft theme via the Admin API (`themeFilesUpsert`).

- `sections/au-hero-video.liquid` – single hero video (autoplay, muted, loop,
  playsinline, no controls), poster image, deferred source loading, optional
  9:16 mobile cut.
- `sections/au-does-doesnt.liquid` – "What it does — and what it doesn't"
  two-column section.
- `templates/index.json` – homepage layout.
- `templates/product.json` – product page layout (fake social proof, quantity
  breaks and cross-sell blocks removed).
